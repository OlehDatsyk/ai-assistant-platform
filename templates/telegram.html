Telegram bot

The platform ships a standalone Telegram bot (telegram_service.py) that mirrors this assistant: every message sent to your bot is routed through the same chat pipeline, memory, and model selection used here, and conversations sync back into your account automatically.

  1. Create a bot with @BotFather and copy its token.
  2. Set TELEGRAM_BOT_TOKEN in your .env file.
  3. Run python telegram_service.py in a separate terminal (or as a background service).
  4. Message your bot on Telegram - replies stream back using your default model.
Runs as a separate process from the web app
